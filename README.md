# Bilibili

把 Bilibili 上的课程、讲座加进 Tau，边看边记。视频会先缓存到本机，之后离线也能看；有字幕的视频打开就能跟着字幕读，划一句就能摘进笔记。

## 三步开始

1. **装好插件**：在插件中心安装「Bilibili」，装好后直接启用，不用重启。
2. **添加视频**：在项目的「添加视频」、编辑器或白板里插入视频时选「Bilibili」，粘贴视频链接。
3. **选清晰度**：解析完成后选一个清晰度，视频下载到本机后就能播放。

## 可以做什么

- **记视频笔记**：在项目里添加的视频会打开成左边看、右边记的视频笔记，可以插入时间戳、截取当前帧，详见 [视频笔记](https://taunote.app/docs/video-notes/)。
- **跟着字幕读**：视频自带字幕时直接显示，随播放滚动；没有字幕或对结果不满意，可以改用转录，把语音转成文字。
- **放进笔记和白板**：视频可以插进正文和白板，和其他内容放在一起。
- **作为学习资料**：在 Notebook 里添加视频资料，Tau 会把它转成文字，供 AI 检索和提问。

## 支持哪些链接

- 视频页链接：BV 号、av 号，以及带 `?p=` 的分 P 链接；
- b23.tv 短链。

番剧、付费课程这类需要单独授权的内容不支持。

## 更高的清晰度

不登录也能添加视频，最高 720P。想要更高的清晰度，在插件详情的「设置」里点「扫码登录」，用 Bilibili 手机客户端扫码；也可以选「手动填写」，粘贴浏览器 Cookie 里的 SESSDATA。登录后可选 1080P，1080P+ 和 4K 需要大会员。部分视频的字幕也要登录后才能读到。

登录凭据只保存在你的电脑上，扫码用的二维码也在本机生成。

## 常见问题

**在手机上能用吗？** 不能，Bilibili 插件只在电脑上使用。

**提示「视频流不可用」怎么办？** 这个视频可能需要大会员权限，或者已经失效。登录大会员账号后再试，或者换一个清晰度。
