# Bilibili

把 Bilibili 视频加入 Tau：在编辑器、白板、项目的视频笔记或学习资料的「添加视频」中选择「Bilibili」，粘贴视频链接，解析后选择清晰度即可添加。视频会先缓存到本地再播放，之后离线也能观看，并可用于转写与视频笔记。

支持视频页链接（BV 号、av 号、带 `?p=` 的分 P 链接）和 b23.tv 短链。番剧、课程等需要单独授权的内容暂不支持。

未登录也能添加视频，默认最高 720P。需要更高清晰度时，在「设置 · 账号与连接 · 在线视频」中扫码登录，或手动填写浏览器 Cookie 中的 SESSDATA；1080P+、4K 等清晰度需要大会员。登录凭据只保存在本机设置中，扫码二维码在本地生成。

从插件中心安装并启用。需要较新版本的 Tau 客户端。
