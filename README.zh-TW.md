# Bilibili

把 Bilibili 上的課程、講座加進 Tau，邊看邊記。影片會先快取到本機，之後離線也能看；有字幕的影片開啟就能跟著字幕讀，選取一句就能摘錄進記事。

## 三步開始

1. **裝好外掛**：在外掛中心安裝「Bilibili」，裝好後直接啟用，不用重新啟動。
2. **加入影片**：在專案的「加入影片」、編輯器或白板裡插入影片時選「Bilibili」，貼上影片連結。
3. **選擇畫質**：解析完成後選擇一個畫質，影片下載到本機後就能播放。

## 可以做什麼

- **記影片筆記**：在專案裡加入的影片會開啟成左邊看、右邊記的影片筆記，可以插入時間戳、擷取目前畫面，詳見 [影片筆記](https://taunote.app/docs/video-notes/)。
- **跟著字幕讀**：影片自帶字幕時直接顯示，隨播放捲動；沒有字幕或對結果不滿意，可以改用轉錄，把語音轉成文字。
- **放進記事和白板**：影片可以插進內文和白板，和其他內容放在一起。
- **作為學習資料**：在 Notebook 裡加入影片資料，Tau 會把它轉成文字，供 AI 檢索和提問。

## 支援哪些連結

- 影片頁連結：BV 號、av 號，以及帶 `?p=` 的分 P 連結；
- b23.tv 短連結。

番劇、付費課程這類需要單獨授權的內容不支援。

## 更高的畫質

未登入也能加入影片，最高 720P。想要更高的畫質，在外掛詳情的「設定」裡點擊「掃碼登入」，用 Bilibili 手機 App 掃碼；也可以選「手動填寫」，貼上瀏覽器 Cookie 裡的 SESSDATA。登入後可選 1080P，1080P+ 和 4K 需要大會員。部分影片的字幕也要登入後才能讀取。

登入憑證只儲存在你的電腦上，掃碼用的 QR Code 也在本機產生。

## 常見問題

**在手機上能用嗎？** 不能，Bilibili 外掛只在電腦上使用。

**提示「影片串流不可用」怎麼辦？** 這個影片可能需要大會員權限，或是已經失效。登入大會員帳號後再試，或是換一個畫質。
